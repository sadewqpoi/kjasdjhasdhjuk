# رفع الموقع: Netlify (الواجهة والدومين) + Railway (الخادم)

```
الزائر ──► دومينك على Netlify ──► الصفحات والصور الثابتة (مجلد public)
                     │
                     └── /api/* ──► الخادم على Railway ──► القرص الدائم /data
                                                          (قاعدة البيانات + الصور + بوت واتساب)
```

التكلفة التقريبية: Netlify مجاني، وRailway خطة Hobby بحوالي 5 دولارات شهريًا، والدومين حسب المسجّل.

> **لماذا Railway مع Netlify؟** Netlify يعرض الصفحات فقط، ولا يستطيع تشغيل الخادم ولا حفظ قاعدة البيانات ولا تشغيل بوت واتساب.
> لذلك الخادم يعمل على Railway، وكلاهما يُربط بنفس مستودع GitHub ويتحدث تلقائيًا مع كل Push.

---

## 1) رفع المشروع إلى GitHub (مرة واحدة)

1. أنشئ حسابًا في [github.com](https://github.com) إن لم يكن لديك.
2. ثبّت برنامج [GitHub Desktop](https://desktop.github.com) وسجّل دخولك فيه.
3. من البرنامج: **File ← Add local repository** واختر مجلد المشروع `مشجرة العلاط`.
   سيقول إنه ليس مستودعًا، فاضغط **create a repository** ثم **Create repository**.
4. اضغط **Publish repository**، و**أبقِ خيار "Keep this code private" مفعّلًا**.

> الملفات الحساسة لا تُرفع تلقائيًا (محددة في `.gitignore`): مجلد `data` (قاعدة البيانات والصور)، وملف `.env`، و`node_modules`.

لاحقًا، أي تعديل: افتح GitHub Desktop ← اكتب وصفًا ← **Commit** ثم **Push**، فيتحدث الموقعان تلقائيًا.

---

## 2) الخادم على Railway

1. ادخل [railway.com](https://railway.com) بحساب GitHub، واشترك في خطة **Hobby**.
2. **New Project ← Deploy from GitHub repo** واختر مستودع المشروع.
3. **القرص الدائم (أهم خطوة):** داخل الخدمة ← **Settings ← Volumes** (أو زر *+ New ← Volume*) ← اجعل **Mount path** = `/data`.
   بدونه تضيع كل البيانات مع كل تحديث.
4. **Variables** — أضف:

   | المتغير | القيمة |
   |---|---|
   | `NODE_ENV` | `production` |
   | `DATA_DIR` | `/data` |
   | `PUBLIC_URL` | `https://دومينك` (مثل `https://alallat.sa`) |
   | `TRUST_PROXY` | `2` |

   (لا تضف `PORT`، فـ Railway يضبطه بنفسه.)
5. **Settings ← Networking ← Generate Domain**: ستحصل على رابط مثل `alallat-production.up.railway.app`. **انسخه.**
6. انتظر حتى يصبح النشر **Active**، وافتح `https://الرابط/api/health`، فيجب أن يظهر `{"ok":true}`.

---

## 3) الواجهة على Netlify

1. ادخل [app.netlify.com](https://app.netlify.com) بحساب GitHub ← **Add new project ← Import an existing project ← GitHub** واختر المستودع.
2. الإعدادات تُقرأ تلقائيًا من `netlify.toml` (لا تغيّر شيئًا في صفحة الإعداد).
   في نفس الصفحة اضغط **Add environment variables** (أو بعد الإنشاء: **Site configuration ← Environment variables**) وأضف:

   | المتغير | القيمة |
   |---|---|
   | `API_URL` | رابط Railway الذي نسخته، مثل `https://alallat-production.up.railway.app` |

3. اضغط **Deploy**. إذا نسيت المتغير يفشل النشر برسالة تشرح المطلوب؛ أضفه ثم **Deploys ← Trigger deploy ← Deploy site**.
4. **الدومين:** **Domain management ← Add a domain** واكتب دومينك، ثم اتبع التعليمات:
   - إذا اشتريته من Netlify: يُربط مباشرة.
   - إذا كان عند مسجّل آخر: إما تغيّر الـ Nameservers إلى التي يعطيك إياها Netlify (الأسهل)، أو تضيف السجلات التي يطلبها.
5. شهادة HTTPS تُفعَّل تلقائيًا خلال دقائق بعد ربط الدومين.

---

## 4) نقل بياناتك الحالية (الحسابات، المشجرة، الوصايا، الصور…)

1. **على جهازك** (والموقع يعمل محليًا): لوحة الإدارة ← **الإعدادات** ← **تنزيل نسخة احتياطية الآن**. سيُحمَّل ملف `alallat-backup-….tar.gz`.
2. **على الخادم الجديد:** أول مرة لا يوجد حساب مدير بعد. في Railway ← **Variables** أضف مؤقتًا:

   | المتغير | القيمة |
   |---|---|
   | `BOOTSTRAP_ADMIN_PHONE` | جوالك `05XXXXXXXX` |
   | `BOOTSTRAP_ADMIN_PASSWORD` | كلمة مرور قوية (8 أحرف على الأقل) |

   يُعاد النشر تلقائيًا ويُنشأ حساب المدير (لا يفعل شيئًا إذا كان هناك مدير مسبقًا). **احذف المتغيرين بعد الاستعادة.**
3. ادخل بهذا الحساب على **رابط Railway المباشر** (`https://….up.railway.app`) ← لوحة الإدارة ← الإعدادات ← **استعادة نسخة احتياطية** واختر الملف.
   (نرفعها على رابط Railway مباشرة لأن ملفات النسخ الكبيرة قد تتجاوز حد الحجم عند المرور عبر Netlify.)
4. يُعاد تشغيل الخادم تلقائيًا خلال ثوانٍ، وتصبح كل بياناتك موجودة. **حسابات المدير القديمة تعود كما كانت** (الحساب المؤقت من الخطوة 2 يُستبدل).

---

## 5) بعد الرفع: ما يجب ضبطه

- **بوت واتساب:** ربطه لا يُنقل. لوحة الإدارة ← الإعدادات ← طرق التحقق ← بوت واتساب ← امسح رمز QR من جوال رقم البوت (واتساب ← الأجهزة المرتبطة). وافصل ربطه من جهازك القديم حتى لا يعمل في مكانين.
- **بوابات الدفع:** البوابة التجريبية تختفي تلقائيًا في الإنتاج. أضف بوابتك الحقيقية من تبويب "بوابات الدفع"، وضع رابط الـ Webhook الظاهر فيها في لوحة البوابة (يبدأ بدومينك).
- **واتساب الرسمي (إن استخدمته):** رابط الـ Webhook في Meta: `https://دومينك/api/whatsapp/webhook`.
- **حساب مدير التطوير** (`0500000000`): احذفه أو غيّر كلمة مروره بعد الاستعادة، لأنه موجود في النسخة.

---

## 6) النسخ الاحتياطي الدوري

- نزّل نسخة احتياطية من لوحة الإدارة **أسبوعيًا على الأقل** واحفظها في مكان آمن (Google Drive مثلًا).
- القرص الدائم في Railway يحفظ البيانات بين التحديثات وإعادة التشغيل، لكنه ليس بديلًا عن نسخة لديك.

---

## حل المشاكل

| المشكلة | الحل |
|---|---|
| الموقع يفتح لكن الدخول والبيانات لا تعمل | قيمة `API_URL` في Netlify غير صحيحة (صحّحها ثم Trigger deploy)، أو الخادم متوقف (افتح `/api/health` على رابط Railway). |
| البيانات تختفي بعد كل تحديث | القرص الدائم غير مركّب على `/data`، أو `DATA_DIR` غير مضبوط. |
| فشل النشر على Railway | افتح **Deployments ← View logs**. المشروع يحتاج Node 24 (محدد في `package.json`). |
| تعديلات الواجهة لا تظهر | تأكد من Push في GitHub Desktop، ثم حدّث الصفحة في المتصفح. |
